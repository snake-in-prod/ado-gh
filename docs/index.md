# ado

`ado` is a command-line tool for Azure DevOps, modeled on the GitHub CLI (`gh`).
It brings pull requests, repositories, work items, pipelines and other Azure
DevOps concepts to the terminal.

- [Install](install.md)
- [Getting started](getting-started.md)
- [Authentication](auth.md): personal access tokens and Microsoft Entra ID
- [Differences from `gh`](gh-differences.md)
- [Extensions](extensions.md): write and install `ado-<name>` commands
- [Command reference](reference/index.md)
